## What it does

`main.py` (Python 3, standard library only, no network) writes one original
roast line to `/output/entry.txt`, validates that it is 1–200 characters and
not only whitespace, then re-reads the file to verify the contents match
exactly.

## The line

> My robot vacuum has mapped my entire house in 4K and still eats the same charging cable every single day.

(105 characters)

## Run it

```sh
python3 main.py
```

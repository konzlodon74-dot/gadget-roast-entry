Entry for the make.fun bounty [One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

## What it does

`main.py` (Python 3, standard library only, no network) writes one original
roast line to `/output/entry.txt`, validates it is 1–200 characters and not
only whitespace, then re-reads the file to verify the written text matches
exactly.

## The roast

> My fitness tracker counts the walk to the fridge as a workout and my actual workout as a nap.

## Run it

```sh
python3 main.py
```
